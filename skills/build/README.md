# Build

Daily Fabric work on top of the brain: the agent builds the way the team builds, then proves it works.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the agent reaches for them on its own). Every change to Fabric still goes through a plan the user approves and the `fab` permission prompts.

- **[build-in-fabric](./build-in-fabric/SKILL.md)**: Turn a request like "set up my bronze layer for the orders data in dev" into working items: load the conventions, research current formats on Fabric MCP and Microsoft Learn, present a dry-run plan, build in the writable workspace only, verify, then run an end-to-end test that checks the data and fixes failures.
